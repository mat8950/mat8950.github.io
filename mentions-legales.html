Données personnelles

L'éditeur ne collecte aucune donnée personnelle. Le site n'a ni compte utilisateur, ni formulaire, ni cookie, ni outil de mesure d'audience, ni publicité.

Stockage local du navigateur

Le site enregistre vos préférences dans le localStorage de votre navigateur pour les retrouver à la prochaine visite :

  • thème, mode compact, barre latérale repliée ;
  • favoris et leur ordre ;
  • musique activée ou non, volume, popup de bienvenue déjà vue ;
  • dossier ouvert, dossiers dépliés, position de défilement ;
  • date de dernière visite (pour la section « Nouveautés »).

Ces informations restent sur votre appareil et ne sont jamais envoyées à l'éditeur ni à un tiers. Elles servent uniquement à des fonctions que vous utilisez : elles ne demandent donc pas de consentement. Pour les effacer, supprimez les données de ce site dans les paramètres de votre navigateur.

Les fichiers que vous importez (favoris .json, marque-pages .html) sont lus dans votre navigateur. Ils ne quittent pas votre appareil.

Hébergement et journaux de connexion

Comme tout hébergeur, GitHub enregistre l'adresse IP des visiteurs pour la sécurité du service (documentation GitHub Pages). GitHub traite ces données selon sa déclaration de confidentialité. L'éditeur n'a pas accès à ces journaux.

Services tiers

Les polices et les bibliothèques JavaScript sont servies depuis ce site.

Les petites icônes des sites référencés sont chargées depuis le service de favicons de Google (www.google.com/s2/favicons). Pour les afficher, votre navigateur envoie à Google votre adresse IP et le nom du site dont l'icône est demandée. Aucun cookie n'est déposé par ce site et l'adresse de la page consultée n'est pas transmise (en-tête Referer désactivé). Google traite ces données selon ses règles de confidentialité.

Quand vous cliquez sur un marque-page, vous quittez ce site : la politique de confidentialité du site visité s'applique alors.

Le RGPD vous donne un droit d'accès, de rectification et d'effacement de vos données. L'éditeur ne détient aucune donnée vous concernant. Pour les journaux de connexion, adressez-vous à GitHub. Vous pouvez aussi saisir la CNIL.
